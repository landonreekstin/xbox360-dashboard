# xbox360-dashboard

A recreation of the Xbox 360 "Blades" dashboard (2005) as a Hyprland desktop: a
[Quickshell](https://quickshell.outfoxxed.me/) shell (QML) plus a small controller daemon
that lets a gamepad drive the whole desktop.

It is packaged and configured by
[landonreekstin/nixos-config](https://github.com/landonreekstin/nixos-config)
(`pkgs/xbox360-dashboard` and its Hyprland `xbox360` desktop), which supplies everything
host-specific. This repo holds only the program itself.

## Layout

| Path | What |
|---|---|
| `shell/` | The Quickshell config: `shell.qml` and every blade, menu, page and the Guide |
| `shaders/blade.frag.in` | The blade surface shader, with `@N@ @KY@ @KD@ @CI@ @CR@` placeholders the Nix side fills from its colour/geometry config, then compiles with `qsb` to `shell/blade.frag.qsb` |
| `pad/xbox360-pad.py` | Controller daemon: Guide chord, desktop mouse/keyboard emulation via uinput, per-app passthrough |
| `pad/xbox360-games.py` | Games Library data (installed Steam/Heroic games as JSON) |
| `pad/xbox360-jellyfin-play.py` | Plays a Jellyfin item in mpv, reporting progress back |
| `pad/xbox360-audio.py` | Guide -> Audio: switches an output + microphone pair |

## Not in here

- **`shell/Config.js`** is generated by the Nix side (`.pragma library`, one `var` per
  setting: palette, monitors, menus, command paths). It is gitignored.
- **The Convection font and dashboard sounds** are Microsoft's and are fetched separately
  (`pkgs/xbox360-assets` in nixos-config); they are never committed here.

## Running

Normally through the "Xbox 360 Dashboard" login session that nixos-config sets up. For
working on the QML with hot reload, see `CLAUDE.md`.
